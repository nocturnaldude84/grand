# Grand Used Furniture

A simple furniture showcase website for **Grand Used Furniture, Kaloor, Kochi**.

Built as a lightweight, single-page catalogue to showcase available furniture without ecommerce or online ordering.

### Features

* Furniture image carousel
* Furniture video carousel
* Responsive design
* WhatsApp contact integration
* Mobile-friendly navigation
* Simple contact section
* Hosted via GitHub Pages / Cloudflare Pages
